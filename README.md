# Rajiv Bhardwaj — Portfolio (Plain Node.js)

A modern, professional, interview-ready Full Stack Developer portfolio.
Built with **plain Node.js** (no Express, no framework) + a single static HTML page,
**Tailwind CSS**, and **vanilla JavaScript**.

> Smallest-footprint stack. No React, no bundler beyond Tailwind's CLI.

## Features

- Sticky glassmorphism navbar with active-section indicator (scrollspy)
- Hero with typing animation, gradient text, animated profile placeholder, floating chips, CTA buttons
- Skill cards categorized by domain (Frontend, Backend, DB, Programming, AI/ML, Tools) — rendered from a JS data array
- Filterable featured projects with hover effects, faux screenshots, tech badges, Live Demo + GitHub links
- Education / experience / milestone timeline with alternating layout
- GitHub stats, top languages, streak, and contributions chart (light + dark variants)
- Certification cards with hover animations
- Working contact form posting to `POST /api/contact` (handled by the Node.js server)
- Footer with social links and back-to-top
- Loading screen, mouse-aware particle background, cursor glow, scroll progress bar
- Dark / light theme toggle (no flash, persisted in `localStorage`)
- Fully responsive, mobile-first
- SEO basics: meta tags, Open Graph, JSON-LD, sitemap, robots.txt
- Accessibility-aware: focus rings, ARIA labels, `prefers-reduced-motion` support

## Stack

| Layer       | What's used                                                       |
| ----------- | ----------------------------------------------------------------- |
| Server      | Plain `http` module from Node.js (no Express)                     |
| Templating  | A single `index.html` (no templating engine)                      |
| Styles      | Tailwind CSS (compiled via Tailwind CLI) + custom CSS variables   |
| Scripting   | Vanilla JavaScript (no framework, no bundler)                     |
| Icons       | [Feather Icons](https://feathericons.com) via CDN + inline SVGs   |

## Getting Started

Requires **Node.js 18+**.

```bash
# 1. Install Tailwind CLI (only dev dep)
npm install

# 2. Build CSS once + start server (recommended for local development)
npm run dev          # tailwind --watch + node server.js (concurrently)

# OR step by step:
npm run css:build    # one-shot Tailwind build into public/styles.css
npm start            # node server.js  →  http://localhost:3000
```

The dev script uses `concurrently` to run Tailwind in watch mode and the Node.js server in parallel.

### Production

```bash
npm run build        # Tailwind --minify
npm start            # node server.js (binds 0.0.0.0:$PORT, defaults to 3000)
```

Set `PORT` and `HOST` env vars to customize. The server gzips nothing by default — put a reverse proxy (Nginx, Caddy) or platform (Railway, Render, Fly.io) in front for compression and TLS.

## How the Server Works

`server.js` is ~100 lines of vanilla Node.js using the built-in `http` module:

- Streams files from `/public` with proper MIME types and a small cache header
- Defends against path traversal
- Provides `POST /api/contact` — validates payload, currently logs to stdout
  (replace with `nodemailer`, a database, or a 3rd-party service like Resend/SendGrid for real email delivery)
- SPA-style fallback to `index.html` for unknown routes

## Hooking Up Real Email

Open `server.js` and find the `[contact]` log line. Replace with your delivery of choice — for example, with [`nodemailer`](https://nodemailer.com):

```js
// npm install nodemailer
const nodemailer = require("nodemailer");
const transporter = nodemailer.createTransport({ /* SMTP config */ });
await transporter.sendMail({
  from: '"Portfolio" <noreply@yourdomain>',
  to: "you@yourdomain",
  subject: `New message from ${name}`,
  text: `${message}\n\n— ${name} <${email}>`,
});
```

## Deploy

- **Any Node host** (Railway, Render, Fly.io, VPS): `npm install && npm run build && npm start`
- **Static hosting** (Netlify, GitHub Pages, Cloudflare Pages): you can publish just `public/` if you don't need the contact API. Build CSS first with `npm run css:build`.
